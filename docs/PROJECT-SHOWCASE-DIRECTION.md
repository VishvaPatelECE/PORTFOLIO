## Composition

Use three large, distinct project scenes with actual engineering evidence. Each can occupy a shallow three-dimensional presentation plane, with restrained pointer tilt and scroll-responsive depth. Keep project names, a single-sentence introduction and an Open project action in readable HTML beside or below the visual. Avoid repeating the small foil identity card from the earlier hero.

The existing title/summary/action rows need a large evidence area. Retain the current gold/cyan world and actual Gateway, Matrix and Constellation fields. Motion follows selection, scrolling and inspection; it is not an endless card rotation.

## Motion sequence

1. The next project becomes visible with a slight angle and depth offset.
2. It settles into a readable view as it reaches the main viewing area. Native vertical scrolling stays in control.
3. A fine pointer gives a small bounded tilt and light response on the cover. Touch/focus provides direct selection without requiring hover.
4. Open project enters the complete case study or instrument. Project identity and destination are always visible.
5. Problem / Approach / Evidence disclosures reveal technical detail when requested. Key information is not available only on a hidden back face.

Mobile and reduced-motion versions present the same evidence in ordinary flow. Home-wide Pause applies to decorative cover motion and fields; offscreen and hidden scenes stop their work.
