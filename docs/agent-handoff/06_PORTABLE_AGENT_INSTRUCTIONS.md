2. State one specific design hypothesis and the evidence it uses.

4. Review the actual integrated page at required sizes. Test controls, keyboard/touch, reduced motion, errors and relevant performance; do not infer runtime quality from a screenshot.
5. Run focused checks and report exact result/warnings.
6. Separate implemented, technically verified, visually inspected, and owner accepted.
7. Stop at the stated scope and report the next useful step.
